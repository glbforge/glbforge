(#47). The mechanical floor was silent — `pnpm docs:check` is green, which is
what it should be an hour after it was introduced and every counted fact was
corrected. So the whole pass was the part a checker cannot do: read what
shipped, then read what a visitor is told, and find the difference.

Three capabilities were in `CHANGELOG.md`'s Unreleased section and described
nowhere a reader looks. All three are mine to fix as copy; none of them is a

notification anywhere in `packages/mcp/src`, `buildLod` still calls

Against the roles roster this pass took none, by design — see the skill. The

### L12 · `fixed` · the Forge section still told visitors the forge only eats flat artwork

`--matte auto` shipped (`matte/border@2`), and the landing page's Forge card
and Forge section were both written before it: "Image-to-3D models produce
mush from flat graphics… traces the silhouette exactly". A visitor reading
either one concludes a photo is refused, which is what the Studio used to do
and is the exact dead end the matte was built to remove. The word "matte"
appeared once on the whole page, in a "Shipping now" bullet added the same
morning.

Both now say it, with the properties that make it honest: deterministic
connectivity, no model download, and a cut that is previewable with a stated
confidence before any geometry exists.

### L13 · `fixed` · USDZ export card omitted node animation, next to a card promising it

The Export card listed "UsdPreviewSurface materials, UsdSkel skeletons and
blend shapes" — written before `toUsdz` learned to bake a moving node as
`xformOp:transform` time samples. The new Animate card promises AR Quick Look
plays a baked clip, so the page contradicted itself for anyone who checked
the export capability before believing the animation one.

### L14 · `fixed` · `glbforge companion --hooks` existed only in the CHANGELOG

`--hooks` / `--hooks-project` / `--no-hooks-install` install Claude Code
hooks so every session on the machine shows its start, permission prompts and
finish on the companion (`packages/cli/src/companion-cmd.ts:66`). It was in no
command list, no card, and neither README — the CHANGELOG entry ("every
session on the machine has a face") was the only place it was ever written
down. Now in the companion card, the `llms.txt` companion bullet with all
three flags, and the README command line beside `--mcp`.

This one is worth noting for what it says about the checker: `docs:check`
verifies every CLI *verb* reaches the `## Commands` list, and cannot see a
*flag*. Mechanizing flags would flag dozens of deliberate omissions, so the
gap stays with this pass on purpose rather than becoming a noisy rule.
