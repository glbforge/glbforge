# Visibility run — 2026-09-28 — baseline

**Engines:** perplexity, google

The first probe, and the one that motivated the apparatus. Perplexity was
driven headless in the built-in browser (no login, live retrieval); Google was
read as organic page-1 results for the optimize query (no AI Overview triggered,
consent-gated). Gemini and ChatGPT need the maintainer's logged-in Chrome and
were not run — recorded as not-run, not as passes.

The split is clean and it is the whole point. **Named** queries retrieved
glbforge.dev, github.com/glbforge and jsdelivr and produced an accurate,
near-complete feature account — the content surface (`llms.txt`, README) works
once the name is in the prompt. **Undirected** queries — the words a person or
agent uses before they know GLBForge exists — surfaced competitors every time
and GLBForge not once, including the MCP-agent niche where GLBForge is in the
official registry as `dev.glbforge/glbforge`. Google organic page 1 for the
core optimize query is the same story: OptimizeGLB, Objectverse, 3D AI Studio,
Khronos glTF-Compressor, a Blender add-on, RAUM, gltf-transform — no GLBForge,
and the discovery is happening in Reddit / the three.js forum / YouTube, where
GLBForge has no footprint at all.

Conclusion: this is a demand-side discovery gap, not a content gap. The fix is
off-page presence (ecosystem lists, ecosystem threads, comparison content) plus
on-page answers pitched at these exact undirected phrasings — tracked here as
the numbers move.
